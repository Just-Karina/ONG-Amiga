# ONG-Amiga

## O que é?
Software desenvolvido para aprendizado, onde uma instituição fictícia (ONG Mão Amiga) precisa digitalizar as suas operações.

## Como foi desenvolvido?
Estou utilizando o [Node.JS] para gerenciar as dependencias, com o framework [Expo](https://expo.dev/) que utiliza de [React Native](https://reactnative.dev/).

## Como rodar?
- Abra o terminal na raiz do projeto
- **Caso use Node.JS**:
  - npm install
  - npx expo start
